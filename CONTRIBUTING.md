# Contributing

Every new method needs a reviewed contract, documented assumptions, independent oracle, golden fixture, fault-injection tests and report evidence mapping. Add clinical knowledge as a versioned resource linked to tests; do not place a universal clinical threshold in a prompt.

Run python -m pytest and build the wheel before proposing a change. Include failures and limitations. Changes to source/skills intentionally invalidate existing run approvals. Keep real data, credentials, generated patient-level artifacts and speculative claims out of the repository.

No live LLM, MCP integration or new dependency should be added without a concrete supported task. Resolve public naming and licenses before publication.
