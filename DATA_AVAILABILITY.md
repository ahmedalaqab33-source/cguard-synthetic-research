# Data and release boundary

Only reviewed original software, documentation and explicitly invented demonstration
materials are distributed. No clinical data, protected derivatives, participant workbooks,
credentials, private research reports, model artifacts, questionnaire instruments, hosting
configuration or original Git histories are included. Do not pass restricted records into
the demonstration or publish private runtime output. No institutional endorsement or
clinical validation is implied. Dependency licenses remain separate. Source ownership and
MIT release authority are established by the owner's confirmation or retained existing
MIT copyright/author metadata for this exact original implementation.
